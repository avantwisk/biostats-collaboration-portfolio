## Repository Overview

This is an academic portfolio repository for the MSc Biostatistics "Biostatistical Collaboration" course module. It contains educational materials, readings, and resources related to biostatistical consulting and collaboration skills.

## Repository Structure

The repository is organized into two main blocks, each containing multiple sessions:

- **Block 1/**: Sessions 1-4 covering foundational collaboration concepts
  - ASCCR Framework (Ask, Structure, Communicate, Clarify, Report)
  - LISA Collaborative Attitude
  - POWER Structure for collaboration meetings
  - Co-authorship guidelines

- **Block 2/**: Sessions 1-8 covering advanced topics
  - Professional roles and conduct in biostatistics
  - Grant proposal writing strategies
  - Research question framing
  - Statistical reporting standards
  - Ethics and scientific integrity

## Nature of This Repository

This is a **document portfolio repository**, not a software project. There is:
- No code to compile, build, or test
- No package managers or dependencies
- No runtime environment

All content consists of PDF readings and educational materials organized by course session.

## Working with This Repository

When asked to help with this repository:
- Focus on organizing and categorizing documents
- Help create summary documents or indices if requested
- Assist with git operations for tracking document additions
- Do not attempt to run build commands or tests
